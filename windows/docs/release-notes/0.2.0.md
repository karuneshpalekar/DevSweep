# DevSweep for Windows 0.2.0 (release candidate)

The parity and polish release. It follows the Mac app's structure in a Windows 11 look.

## New and changed

- **Projects.** Show filter (All / On this PC / On GitHub) with counts, account filter, search, a Get a
  project menu (Add by URL, Publish a folder, Find all repos on this PC, Add folder, Refresh), Download
  buttons, and a detail panel with the "Is it safe to remove from this PC?" checklist, a plain verdict and
  Open in editor / Show in File Explorer / Open on GitHub / Push / Publish / Remove. Clone, Publish, Add by
  URL and Add account sheets. Local clones are listed even with no GitHub account.
- **Find all repos on this PC.** A deep search of every fixed drive (Downloads, Desktop, Program Files and
  other drives included), skipping only system and dependency folders. It reads folder names only, never
  opens cloud-only files, and says what it searched. WSL repos of running distros are listed read-only.
- **Open in editor.** VS Code, Insiders, Visual Studio, Rider, Cursor and Windsurf are detected; pick a
  default in Settings.
- **Health.** Tools and versions as a list with a side panel, a winget / Scoop / Chocolatey report,
  Security actions (Show in File Explorer, Recycle Bin, Ignore) and Ports (Stop, with confirmation).
- **Settings.** One page like the Mac's: GitHub accounts with the identity editor, Downloads folder,
  project folders, default editor, ignored items, Permissions and privacy, Troubleshooting (copy report).
- **Home and sidebar.** Free-space card, counts on each place, "Needs your attention" cards, blocked-folder
  and rule-pack banners, first-scan states.
- **Tray.** Left click opens a flyout (free space, alerts, recent projects, Scan now); right click keeps the
  menu.
- **Remove anyway.** As on the Mac, a project that isn't fully backed up can still be removed: the confirm
  lists exactly what would be lost, and the folder goes to the Recycle Bin or quarantine, restorable from
  History. The `devsweep` command line stays strict and never removes an unsafe project.
- **Clean up and Review.** A Quit <app> button (asks first, closes windows politely, never kills), pinned
  action footers in every side panel, per-item progress while cleaning.
- **Title bar.** The gear button is gone (Settings is in the sidebar); the light/dark button stays.
- **Clean up** no longer ends with the "About this scan" panel; the scan report is still one click away in Settings, Troubleshooting, Copy scan report.
- **AI editors and the Claude app.** Caches of VS Code Insiders, Antigravity, Kiro, Trae, Void and the Claude
  desktop app, as for VS Code, Cursor and Windsurf. Each editor is looked at only while it is installed; once it
  is gone, its folders show up as leftovers. Editor caches are listed under Caches. Claude's `vm_bundles` (the
  virtual machine it runs code in) is never offered.
- **Ollama models** go to the Recycle Bin: the model's manifest and the layers no other model uses. Layers
  shared with another model stay.
- **Motion, as on the Mac.** The open section shows its rows in the sidebar (Clean up's kinds with sizes, the tabs
  of Projects and Health), opening and closing as you move between sections, with a quiet highlight that eases
  between rows. On a short window the update card and alerts fold into one line to make room (click it to show
  them). Hover and selection fills ease in and out, sheets fade out as well as in, Review cross-fades
  into its results, and the update card fades away on Later. All of it is off when Windows' animation effects
  are off.
- **Polish.** One design system, motion that respects "Animation effects", a contrast check on every screen
  in light, dark and high contrast, and a keyboard-order check.

## Known gaps

- No guided PostgreSQL upgrade yet (planned after this release).
- The browser-profile "parts" list is not shown (the Windows engine does not provide it).
- Not signed: Windows SmartScreen may warn the first time (More info, Run anyway).
