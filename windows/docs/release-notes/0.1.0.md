# DevSweep for Windows 0.1.0

The first Windows release. DevSweep finds what is using your disk on a developer PC, tells you what
each item is and exactly what happens if you remove it, and cleans only after you review it.

## What is in

- **Clean up**: package manager caches (npm, NuGet and more), old tool versions, leftovers from
  apps you removed, and Windows items, from rule packs that cover common developer tools. Every item
  says what it is, what was checked, what you will not lose and how to undo it.
- **Safe by design**: nothing is cleaned without a review step. Things that matter go to the
  Recycle Bin or DevSweep's quarantine and can be restored from History. DevSweep never follows
  shortcuts-to-folders (junctions and symbolic links) out of the place it is cleaning, and never opens
  files that exist only in the cloud (OneDrive).
- **Honest sizes**: when a size is an estimate, partial or could not be read, it says so instead of
  guessing.
- **Projects** and **Health** (tool versions, security findings, open ports) pages. They are off by
  default in this release; turn them on in Settings, Modules.
- A **command line**, `devsweep.exe`, for scans, History and the quarantine.
- **No administrator rights, no account, no telemetry.** Anything that would need an administrator is
  shown as a command for you to run yourself.

## What is not in yet

- Menu bar / tray icon and automatic update checks arrive with the next release. Until then, download
  new versions from the Releases page. (Settings has an update switch, but it contacts nothing yet.)
- The installer and the programs are **not code-signed**, so Windows SmartScreen may warn you the
  first time: click More info, then Run anyway.
- No winget package or MSIX yet.
- Windows 11 22H2 or later on 64-bit Intel/AMD only. Windows 10 and ARM are not supported.

## Your data

History, settings and the quarantine are in `%LOCALAPPDATA%\DevSweep`. Uninstalling keeps them unless
you tick the option to delete them. The quarantine may hold items you can still restore, so it is
never deleted by default.
