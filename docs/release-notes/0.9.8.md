DevSweep 0.9.8 shows all your GitHub repositories in Projects. Everything from 0.9.7 is included.

Requires macOS 14 Sonoma or later. Projects uses the GitHub CLI (`brew install gh`, then `gh auth login`).

## What changed

- **Organization and shared repos appear in Projects.** DevSweep used to list only repos your account owns, so repos in organizations you belong to, and repos shared with you as a collaborator, were missing. It now lists every repo your account can open, across all pages. Archived repos stay hidden.
- **One entry per repo.** If two signed-in accounts can both see a repo, it's listed once, under the account that owns it when that account is signed in.
- The Accounts tab counts every repo an account can reach, so the numbers may go up.

## Install

1. `brew upgrade --cask devsweep` (or `brew install --cask karuneshpalekar/tap/devsweep`), or download **DevSweep-0.9.8.dmg**, open it, and drag DevSweep to Applications. Replace the old copy if asked.
2. A downloaded build isn't notarized by Apple, so allow it once:
   - **macOS 14:** right-click DevSweep in Applications, choose **Open**, then **Open** again.
   - **macOS 15 and later:** try to open it, then go to System Settings, Privacy & Security, and click **Open Anyway**.
   - **Or in Terminal:** `xattr -dr com.apple.quarantine /Applications/DevSweep.app`

## Verify the download

```
shasum -a 256 DevSweep-0.9.8.dmg
```
