DevSweep 0.4 adds **Security** and **Ports** to Health, checks six more tools, and tells you when a project needs a version you don't have. It also includes the 0.3 redesign: four places instead of sixteen sidebar rows.

Requires macOS 14 Sonoma or later.

## New in 0.4

- **Security.** Finds recovery codes, private keys outside `~/.ssh`, cloud service-account keys (even base64-encoded), AWS access-key files, password-manager exports, and `.env` files that git tracks or doesn't ignore. Files are recognised by name and shape; secret values are never kept or shown. Move to Trash (logged in History), fix in Terminal, or mark as handled.
- **Ports.** What's listening on your Mac: dev servers, databases, Docker. See the project folder, whether other devices on your network can connect, and stop a process if you need the port back.
- **Six more tools.** PHP, Rust, the .NET SDK, Flutter, Deno and Bun, plus conda environments under Python.
- **Your projects.** Reads `.nvmrc`, `package.json` engines, `.python-version`, `pyproject.toml`, `go.mod`, Gradle toolchains, `.tool-versions` and more, and flags projects that ask for a version you don't have or one past end of life, with the install command.
- **Home shows the most important problems** across security and tools, grouping repeated files into one line.
- New commands: `devsweep security` and `devsweep ports`.

## From 0.3

- **Home, Clean up, Health**, plus History and Settings. Categories became filter chips.
- **Since last week** on Home: what grew, what's new, what you cleaned.
- **First-launch screen** explaining what DevSweep looks at and which permission prompts to expect.
- **Settings window (⌘,)**: appearance, project folders, ignored items, Full Disk Access status.
- **Admin items run in Terminal** instead of copy and paste.

## Install

1. Download **DevSweep-0.4.0.dmg**, open it, and drag DevSweep to Applications.
2. This build isn't notarized by Apple, so allow it once:
   - **macOS 14:** right-click DevSweep in Applications, choose **Open**, then **Open** again.
   - **macOS 15 and later:** try to open it, then go to System Settings, Privacy & Security, and click **Open Anyway**.
   - **Or in Terminal:** `xattr -dr com.apple.quarantine /Applications/DevSweep.app`

## Verify the download

```
shasum -a 256 DevSweep-0.4.0.dmg
```

It should match `DevSweep-0.4.0.dmg.sha256` attached to this release.
