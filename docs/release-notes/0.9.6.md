DevSweep 0.9.6 shows what a scan is doing and what it found, check by check. Everything from 0.9.5 is included.

Requires macOS 14 Sonoma or later. Projects uses the GitHub CLI (`brew install gh`, then `gh auth login`).

## What changed

- **Honest progress.** The scan names the checks and items still running ("Checking 22 of 50 · Large files, Docker build cache", then "Measuring sizes · 14 of 16 · Chrome cache"). Before, the label showed whichever check started last, usually "Leftovers", for the whole scan.
- **No more endless scans.** A check that runs over 90 seconds is skipped and reported. Measuring an item stops after 60 seconds but keeps the size counted so far, marked "at least", so a huge browser cache is still listed. Items with several folders are measured in parallel.
- **A hint when it's slow.** If a step runs over 20 seconds without Full Disk Access, DevSweep explains that macOS may be waiting on a permission dialog hidden behind the window, with a button to open Full Disk Access.
- **A summary after every scan.** Clean up shows how long the scan took and each check's result (found, nothing found, skipped), plus any folders macOS blocked. "Nothing to clean" now says every check ran.
- **Clearer project folders.** Settings lists the folders that exist, collapses suggested ones that don't, flags folders macOS blocks, and treats `~/Code` and `~/code` as one.
- **Copy scan report.** Settings, Troubleshooting copies a plain-text report (macOS version, Full Disk Access, folder access, every check's timing and result) to paste into an email or GitHub issue. It has no file or project names. The command line has `devsweep scan --report`.

## Install

1. `brew upgrade --cask devsweep` (or `brew install --cask karuneshpalekar/tap/devsweep`), or download **DevSweep-0.9.6.dmg**, open it, and drag DevSweep to Applications. Replace the old copy if asked.
2. A downloaded build isn't notarized by Apple, so allow it once:
   - **macOS 14:** right-click DevSweep in Applications, choose **Open**, then **Open** again.
   - **macOS 15 and later:** try to open it, then go to System Settings, Privacy & Security, and click **Open Anyway**.
   - **Or in Terminal:** `xattr -dr com.apple.quarantine /Applications/DevSweep.app`

## Verify the download

```
shasum -a 256 DevSweep-0.9.6.dmg
```
