DevSweep 0.9.7 lets you choose which browser profiles' caches to clean. Everything from 0.9.6 is included.

Requires macOS 14 Sonoma or later. Projects uses the GitHub CLI (`brew install gh`, then `gh auth login`).

## What changed

- **Choose profiles in Review.** Chrome cache is still one item, but in Review it lists every Chrome profile with a checkbox, all ticked by default, plus **Select all** and **Select none**. Untick a profile to keep its cache. The size, the Clean button and the commands follow your choice, and the other profiles aren't touched.
- **Profiles you can recognise.** Each profile shows the name Chrome gives it, its account, and when it was last used. Two profiles with the same name also show their folder.
- **The detail panel** lists every profile with its cache size.
- **Edge and Brave** work the same way.
- Logins, passwords, bookmarks and history are never touched. Only cache folders are cleaned.

## Install

1. `brew upgrade --cask devsweep` (or `brew install --cask karuneshpalekar/tap/devsweep`), or download **DevSweep-0.9.7.dmg**, open it, and drag DevSweep to Applications. Replace the old copy if asked.
2. A downloaded build isn't notarized by Apple, so allow it once:
   - **macOS 14:** right-click DevSweep in Applications, choose **Open**, then **Open** again.
   - **macOS 15 and later:** try to open it, then go to System Settings, Privacy & Security, and click **Open Anyway**.
   - **Or in Terminal:** `xattr -dr com.apple.quarantine /Applications/DevSweep.app`

## Verify the download

```
shasum -a 256 DevSweep-0.9.7.dmg
```
