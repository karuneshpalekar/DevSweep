DevSweep 0.2 adds **Runtimes and versions**: a screen that checks whether the tools you rely on are still supported, which copy your shell actually runs, and how to fix what isn't right.

Requires macOS 14 Sonoma or later.

## New: Runtimes and versions

- **Every install of Node.js, Python, Java, PostgreSQL, Go and Ruby**, whoever installed it: Homebrew, nvm, fnm, Volta, asdf, mise, pyenv, uv, rbenv, RVM, SDKMAN, the official installers, Postgres.app, IDE-bundled JDKs, and macOS itself.
- **Which one you actually use.** DevSweep asks your login shell for its PATH, so it can tell you when, say, a python.org copy is running instead of Homebrew's newer one.
- **Support status from endoflife.date**: release date, end of support, latest patch and LTS, cached for a day and usable offline. Versions are labelled Supported, Ending soon (within 120 days) or End of life.
- **Problems it points out**: end-of-life versions, the same tool installed by several managers, shadowed versions, missing patch releases, PostgreSQL servers nobody runs, deprecated or outdated Homebrew packages, and pending macOS updates.
- **Fixes for the tool that owns each install** (`brew`, `nvm`, `pyenv`, `sdk` and so on). Copy them, or choose **Run in Terminal**: a window opens, lists the commands and waits for Return before anything runs.
- **Guided PostgreSQL upgrade** for Homebrew installs. It backs up every database, counts the rows in every table, switches to the new version, restores, counts again and compares. It asks before each change and before removing the old version. The backup stays in `~/DevSweep Backups`.
- **Needs attention** on the Overview lists the most important problems.
- New command: `devsweep runtimes` (add `--json` for scripts).

## Install

1. Download **DevSweep-0.2.0.dmg**, open it, and drag DevSweep to Applications.
2. This build isn't notarized by Apple, so allow it once:
   - **macOS 14:** right-click DevSweep in Applications, choose **Open**, then **Open** again.
   - **macOS 15 and later:** try to open it, then go to System Settings, Privacy & Security, and click **Open Anyway**.
   - **Or in Terminal:** `xattr -dr com.apple.quarantine /Applications/DevSweep.app`
3. For complete cleanup results, give DevSweep **Full Disk Access** in System Settings, Privacy & Security.

## Verify the download

```
shasum -a 256 DevSweep-0.2.0.dmg
```

It should match `DevSweep-0.2.0.dmg.sha256` attached to this release.
