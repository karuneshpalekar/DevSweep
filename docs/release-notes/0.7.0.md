DevSweep 0.7 can check in on its own: it opens at login in the menu bar, scans on a schedule, and sends a notification only when something needs attention. It includes everything from 0.3 to 0.6: the simpler layout, Security, Ports, project version checks, Docker, large files, backups, Chrome profiles, and Projects (which replaces RepoShelf).

Requires macOS 14 Sonoma or later.

## New in 0.7

- **Open at login.** DevSweep stays in the menu bar after you close its window, so it can scan while you work.
- **Scheduled scans.** Every day or week, at a time you choose. They're read-only, and nothing is ever cleaned automatically. A Mac that was asleep or off at the scheduled time scans when it wakes.
- **Alerts.** A notification when the disk passes a limit you set (70 to 95%), something grows by more than 1 to 10 GB in a week, a tool you use reaches end of life, or a new file that looks like a secret appears. Each can be switched off.
- **Quiet by design.** Several problems become one notification. Each is announced once, and you're reminded only after a few days if it's still there. The first scan after you turn on alerts treats existing secret files as already known, so you aren't alerted about files you've seen.
- **Notifications open the right place.** Clicking one brings DevSweep forward on Clean up, Health or Security.
- **Home shows the next scheduled scan.**
- **Settings, Scans and alerts** has all of this, plus a test notification.

## Install

1. Download **DevSweep-0.7.0.dmg**, open it, and drag DevSweep to Applications.
2. This build isn't notarized by Apple, so allow it once:
   - **macOS 14:** right-click DevSweep in Applications, choose **Open**, then **Open** again.
   - **macOS 15 and later:** try to open it, then go to System Settings, Privacy & Security, and click **Open Anyway**.
   - **Or in Terminal:** `xattr -dr com.apple.quarantine /Applications/DevSweep.app`
3. To get alerts, open Settings, Scans and alerts, turn on **Scan on a schedule**, and allow notifications when macOS asks. Turn on **Open DevSweep at login** so it's always running.
