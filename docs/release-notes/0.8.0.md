DevSweep 0.8 brings the rest of RepoShelf into Projects: **Cleanup**, **Accounts** and **Activity**, each with its own tab. It includes everything from 0.3 to 0.7: the simpler layout, Security, Ports, project version checks, Docker, large files, backups, Chrome profiles, Projects, and scheduled scans with alerts.

Requires macOS 14 Sonoma or later. Projects uses the GitHub CLI (`brew install gh`, then `gh auth login`).

## New in 0.8

- **Cleanup.** Local copies you haven't opened in a while: 1 week to 3 months, you choose (3 weeks by default). Biggest first, with what removing them would free. Fully backed-up projects are marked safe and can be removed one by one or all at once; the others say what's holding them back (commits not pushed, uncommitted changes).
- **Accounts.** Every GitHub account you're signed in to, with how many repositories it has, what's on this Mac, and the name and email its commits use. Edit them and press Save. **Add account** saves the identity first, then opens GitHub's sign-in in Terminal. Clones from organisations you're not signed in to are listed separately.
- **Activity.** A running trail of downloads, removals, publishes, pushes, added repos, identity changes and sign-ins, by day. The trail RepoShelf kept (downloads, removals and publishes) is brought over the first time.
- **A gear in Projects** opens the GitHub settings directly.
- **Settings, GitHub** shares the same account cards, so there's one way to edit an identity.
- **Safer upgrades.** Older settings files load correctly, so identities and known repos you saved are never lost when DevSweep adds new fields.

## Also in this release

Everything since the last published version (0.1.0 and 0.2.0): the Home, Clean up, Projects and Health layout, Security and Ports, project version checks, Docker, large files, iPhone backups, Chrome profiles, Projects with safe removal and publishing, open at login, scheduled scans and alerts. ## Install

1. Download **DevSweep-0.8.0.dmg**, open it, and drag DevSweep to Applications.
2. This build isn't notarized by Apple, so allow it once:
   - **macOS 14:** right-click DevSweep in Applications, choose **Open**, then **Open** again.
   - **macOS 15 and later:** try to open it, then go to System Settings, Privacy & Security, and click **Open Anyway**.
   - **Or in Terminal:** `xattr -dr com.apple.quarantine /Applications/DevSweep.app`

## Verify the download

```
shasum -a 256 DevSweep-0.8.0.dmg
```

It should match `DevSweep-0.8.0.dmg.sha256` attached to this release.
