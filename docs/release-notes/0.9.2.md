DevSweep 0.9.2 adds an app icon. Everything from 0.9.1 is included.

Requires macOS 14 Sonoma or later. Projects uses the GitHub CLI (`brew install gh`, then `gh auth login`).

## What changed

- **An app icon.** A glowing disk-usage ring on a plain dark square: the used part runs blue to violet, the freed part is mint. Until now DevSweep showed a blank placeholder in the Dock and Finder.

## Install

1. `brew install --cask karuneshpalekar/tap/devsweep` (or `brew upgrade --cask devsweep`), or download **DevSweep-0.9.2.dmg**, open it, and drag DevSweep to Applications. Replace the old copy if asked.
2. A downloaded build isn't notarized by Apple, so allow it once:
   - **macOS 14:** right-click DevSweep in Applications, choose **Open**, then **Open** again.
   - **macOS 15 and later:** try to open it, then go to System Settings, Privacy & Security, and click **Open Anyway**.
   - **Or in Terminal:** `xattr -dr com.apple.quarantine /Applications/DevSweep.app`

## Verify the download

```
shasum -a 256 DevSweep-0.9.2.dmg
```
