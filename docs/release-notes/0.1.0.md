The first release of DevSweep: a Mac app that finds what's safe to clean on a developer's machine, and explains every item before you touch it.

Requires macOS 14 Sonoma or later.

## Install

1. Download **DevSweep-0.1.0.dmg**, open it, and drag DevSweep to Applications.
2. Open DevSweep once. macOS will say it can't check the app for malicious software, because this build isn't notarized by Apple (that needs a paid developer account). To allow it:
   - **macOS 14:** right-click DevSweep in Applications, choose **Open**, then **Open** again.
   - **macOS 15 and later:** try to open it, then go to System Settings, Privacy & Security, scroll down and click **Open Anyway**.
   - **Or in Terminal:** `xattr -dr com.apple.quarantine /Applications/DevSweep.app`

   You only need to do this once.
3. For complete results, give DevSweep **Full Disk Access** in System Settings, Privacy & Security. Without it, macOS hides some app folders.

Prefer to build it yourself? Clone the repo and run `./install.sh` (needs Xcode 15.3+ and XcodeGen).

## What it finds

- **Leftovers from apps you've removed**, matched by bundle ID across 11 Library folders
- **Background services** whose program no longer exists
- **Old IDE versions**: Android Studio and JetBrains settings, stale VS Code and Cursor extensions
- **Android**: system images no emulator uses, old build tools, platforms, NDKs and Gradle versions
- **Xcode**: DerivedData, device support files, superseded simulator runtimes
- **Toolchains**: old Kotlin/Native compilers, Intel builds on Apple silicon, Java older than 11
- **Package caches**: npm, pip, Homebrew, Yarn, CocoaPods, SwiftPM, Gradle, Go, Cargo
- **Idle projects**: `node_modules`, virtualenvs and Pods untouched for 30 days
- **Browser caches and AI models**: Chrome, Edge, Brave, Chrome's on-device model, Whisper, Hugging Face

## How it behaves

- Scanning never changes anything. You review every item, and the exact commands, before confirming.
- Every item has an explanation: what it is, what was checked on your Mac, what happens if you clean it, and how to undo it.
- Anything that might matter goes to the Trash and can be restored from History. Only caches that rebuild themselves are deleted outright.
- No AI, no account and no network needed.

## Verify the download

```
shasum -a 256 DevSweep-0.1.0.dmg
```

It should match `DevSweep-0.1.0.dmg.sha256` attached to this release.
