DevSweep 0.9 adds a Homebrew tap and an in-app update check. Everything from 0.8.2 is included.

Requires macOS 14 Sonoma or later. Projects uses the GitHub CLI (`brew install gh`, then `gh auth login`).

## What's new

- **Install with Homebrew.** `brew install --cask karuneshpalekar/tap/devsweep`. The cask clears macOS's quarantine flag, so the unnotarized app opens without the Gatekeeper steps. Update with `brew upgrade --cask devsweep`.
- **Update check.** DevSweep asks GitHub for the latest release at launch and then about once a day. When a newer one exists, a card appears in the sidebar: **Update** (for Homebrew installs, runs `brew upgrade --cask devsweep` in Terminal) or **Get it** (opens the release page), and **Later** hides that version.
- **Settings, Updates.** Shows the installed version, a **Check now** button, and a switch to turn the automatic check off. The check is one anonymous request; nothing about your Mac is sent.

## Install

1. `brew install --cask karuneshpalekar/tap/devsweep`, or download **DevSweep-0.9.0.dmg**, open it, and drag DevSweep to Applications. Replace the old copy if asked.
2. A downloaded build isn't notarized by Apple, so allow it once:
   - **macOS 14:** right-click DevSweep in Applications, choose **Open**, then **Open** again.
   - **macOS 15 and later:** try to open it, then go to System Settings, Privacy & Security, and click **Open Anyway**.
   - **Or in Terminal:** `xattr -dr com.apple.quarantine /Applications/DevSweep.app`

## Verify the download

```
shasum -a 256 DevSweep-0.9.0.dmg
```
