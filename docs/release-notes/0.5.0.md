DevSweep 0.5 finds four more kinds of things to clean: Docker leftovers, big old files, iPhone backups, and unused Chrome profiles. It includes everything from 0.3 (the simpler layout) and 0.4 (Security, Ports, project version checks).

Requires macOS 14 Sonoma or later.

## New in 0.5

- **Docker.** Build cache, unused images, stopped containers and unused volumes, sized by Docker itself and cleaned with its own prune commands. Containers and volumes are labelled "Holds your data". Nothing shows when Docker isn't running.
- **Large files.** Old installers (.dmg, .pkg, .iso) in Downloads and Desktop, and files over 200 MB you haven't opened in 4 months, judged by Spotlight's last-opened date. Always moved to the Trash, never deleted outright.
- **Backups.** iPhone and iPad backups that are old or replaced by a newer one (it warns when a backup is the only one of that device), and Time Machine local snapshots, which run in Terminal.
- **Chrome profiles.** Profiles unused for 6 months, with whether they're signed in (so synced data is safe) or exist only on this Mac. You delete them from inside Chrome so its profile list stays correct.
- New filters in Clean up: **Large files**, **Docker** and **Backups**.

## Install

1. Download **DevSweep-0.5.0.dmg**, open it, and drag DevSweep to Applications.
2. This build isn't notarized by Apple, so allow it once:
   - **macOS 14:** right-click DevSweep in Applications, choose **Open**, then **Open** again.
   - **macOS 15 and later:** try to open it, then go to System Settings, Privacy & Security, and click **Open Anyway**.
   - **Or in Terminal:** `xattr -dr com.apple.quarantine /Applications/DevSweep.app`

## Verify the download

```
shasum -a 256 DevSweep-0.5.0.dmg
```

It should match `DevSweep-0.5.0.dmg.sha256` attached to this release.
