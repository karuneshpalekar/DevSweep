DevSweep 0.6 adds **Projects**: your repos on this Mac and on GitHub in one list, with a check that tells you whether each is safe to remove. It replaces RepoShelf, and includes everything from 0.3 to 0.5: the simpler layout, Security, Ports, project version checks, Docker, large files, backups and Chrome profiles.

Requires macOS 14 Sonoma or later. Projects uses the GitHub CLI (`brew install gh`, then `gh auth login`).

## New in 0.6: Projects

- **One list for every project.** Repos on GitHub for each account you're signed in to, clones already on your Mac (matched by their `origin`, wherever the folder is), folders with no GitHub origin, and repos you removed earlier, which stay listed with a Download button.
- **Is it safe to remove?** Before a project can leave your Mac, DevSweep checks for commits on any branch that aren't on GitHub, uncommitted or untracked files, and stashes. Only fully backed-up projects can be removed, to the Trash (restorable from History). A removed project downloads back into the folder it came from.
- **Push in one click**, run in Terminal so you see exactly what happens.
- **Download with a strategy.** Blobless, shallow or full, with a size estimate.
- **Per-account commit identity.** Set the name and email for each GitHub account in Settings, GitHub. They're written into every project downloaded with that account, so commits are attributed correctly whatever your global Git identity is. DevSweep warns when an account has none.
- **Accounts without switching.** Each account's own token is used, so the account active in your terminal never changes.
- **Publish a folder to GitHub**, private or public, after a check for files that look like secrets.
- **Add any repo by URL**, for forks and team repos outside your own lists.
- **Idle projects.** "Not opened lately" lists projects untouched for three weeks, with a button to remove the ones that are fully on GitHub.
- **Menu bar** lists your recent projects, and **Home** warns when a project has commits that aren't on GitHub.
- **Moving over from RepoShelf.** DevSweep imports its clone strategies, last-opened times and removed repos the first time Projects loads.

## Install

1. Download **DevSweep-0.6.0.dmg**, open it, and drag DevSweep to Applications.
2. This build isn't notarized by Apple, so allow it once:
   - **macOS 14:** right-click DevSweep in Applications, choose **Open**, then **Open** again.
   - **macOS 15 and later:** try to open it, then go to System Settings, Privacy & Security, and click **Open Anyway**.
   - **Or in Terminal:** `xattr -dr com.apple.quarantine /Applications/DevSweep.app`

## Verify the download

```
shasum -a 256 DevSweep-0.6.0.dmg
```

It should match `DevSweep-0.6.0.dmg.sha256` attached to this release.
