DevSweep 0.9.9 cleans the caches of AI code editors and the Claude app, and lists local AI models. Everything from 0.9.8 is included.

Requires macOS 14 Sonoma or later. Projects uses the GitHub CLI (`brew install gh`, then `gh auth login`).

## What changed

- **AI code editor caches.** Cursor, Windsurf, Antigravity, Kiro, Trae, Void, VS Code Insiders and the Claude desktop app each get their own cache item: web cache, compiled code, GPU cache and downloaded extension installers, which all rebuild on their own. Each asks you to quit that app first, and only appears while the app is installed. Claude's virtual machine (`vm_bundles`) is never offered.
- **Local AI models.** Ollama models are listed one per model and tag, removing only that model's own files and keeping files another model shares. LM Studio models are listed one per downloaded model. Both go to the Trash and can be restored from History.
- **IDE caches sit under Caches** in Clean up, not under Old and unused.
- **A tidier Clean up list.** The "About this scan" section is gone from the list. The summary still shows when a scan finds nothing, and Settings, Troubleshooting still has Copy scan report.

## Install

1. `brew upgrade --cask devsweep` (or `brew install --cask karuneshpalekar/tap/devsweep`), or download **DevSweep-0.9.9.dmg**, open it, and drag DevSweep to Applications. Replace the old copy if asked.
2. A downloaded build isn't notarized by Apple, so allow it once:
   - **macOS 14:** right-click DevSweep in Applications, choose **Open**, then **Open** again.
   - **macOS 15 and later:** try to open it, then go to System Settings, Privacy & Security, and click **Open Anyway**.
   - **Or in Terminal:** `xattr -dr com.apple.quarantine /Applications/DevSweep.app`

## Verify the download

```
shasum -a 256 DevSweep-0.9.9.dmg
```
