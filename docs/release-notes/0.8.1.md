DevSweep 0.8.1 simplifies Settings and polishes the sidebar. Everything from 0.8.0 is included.

Requires macOS 14 Sonoma or later. Projects uses the GitHub CLI (`brew install gh`, then `gh auth login`).

## What changed

- **One Settings page.** Appearance, open at login, scheduled scans, alerts, GitHub accounts, downloads, project folders, ignored items and permissions now sit on a single scrolling page, in that order, instead of separate tabs.
- **Sidebar.** Moving between sections is sequenced: the open section folds away, then the highlight slides to the next one. The highlight also glides between sub-rows.
- **Remove from Mac is red**, like every other delete action, in the project panel, the Cleanup tab and the bulk "Remove safe projects" button.
- **Fixes.** The Folders and Permissions pages could blank the whole window; that is gone along with the separate tabs.
- **README** now shows light mode throughout, plus one dark Home.

## Install

1. Download **DevSweep-0.8.1.dmg**, open it, and drag DevSweep to Applications. Replace the old copy if asked.
2. This build isn't notarized by Apple, so allow it once:
   - **macOS 14:** right-click DevSweep in Applications, choose **Open**, then **Open** again.
   - **macOS 15 and later:** try to open it, then go to System Settings, Privacy & Security, and click **Open Anyway**.
   - **Or in Terminal:** `xattr -dr com.apple.quarantine /Applications/DevSweep.app`

## Verify the download

```
shasum -a 256 DevSweep-0.8.1.dmg
```
