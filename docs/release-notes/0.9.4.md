DevSweep 0.9.4 makes removing a project feel immediate. Everything from 0.9.3 is included.

Requires macOS 14 Sonoma or later. Projects uses the GitHub CLI (`brew install gh`, then `gh auth login`).

## What changed

- **Removing a project shows progress at once.** The row says "Removing…" with a spinner the moment you confirm, instead of looking unchanged for several seconds.
- **The list updates instantly.** As soon as the folder is in the Trash, the project leaves "On this Mac" and shows under "Only on GitHub" with its Download button. The slow full refresh now runs in the background.
- **"Remove safe projects" does the same** for every project it removes.
- **A refresh can't undo a removal.** A refresh asked for while another is running is queued, so stale results no longer bring a removed project back.

## Install

1. `brew upgrade --cask devsweep` (or `brew install --cask karuneshpalekar/tap/devsweep`), or download **DevSweep-0.9.4.dmg**, open it, and drag DevSweep to Applications. Replace the old copy if asked.
2. A downloaded build isn't notarized by Apple, so allow it once:
   - **macOS 14:** right-click DevSweep in Applications, choose **Open**, then **Open** again.
   - **macOS 15 and later:** try to open it, then go to System Settings, Privacy & Security, and click **Open Anyway**.
   - **Or in Terminal:** `xattr -dr com.apple.quarantine /Applications/DevSweep.app`

## Verify the download

```
shasum -a 256 DevSweep-0.9.4.dmg
```
