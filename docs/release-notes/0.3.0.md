DevSweep 0.3 is a redesign for simplicity: four places instead of sixteen sidebar rows, a first-launch screen that explains what DevSweep looks at, and a look at what changed since last week.

Requires macOS 14 Sonoma or later.

## What's new

- **Home, Clean up, Health.** The sidebar now has three sections, plus History and Settings at the bottom. Categories became filter chips in Clean up (Caches, Old versions, Leftovers, Project dependencies), and Runtimes and versions moved into Health.
- **Since last week.** Home shows what grew, what's new, and what you cleaned, compared with your scan from about a week ago. After your first scan it starts collecting.
- **Needs attention.** The four most important problems, on Home and in the menu bar.
- **First-launch screen.** Before the first scan, DevSweep explains what it looks at, what it never does, and which permission prompts macOS may show, with a one-click way to give Full Disk Access instead.
- **Settings window (⌘,).** Appearance, the project folders DevSweep searches, ignored items, and Full Disk Access status.
- **Admin items run in Terminal.** Background services outside your home folder no longer need copy and paste: Run in Terminal lists the commands, waits for Return, and macOS asks for your password there.
- **Simpler menu bar.** Free space, what can be cleaned with a Review button, and the top two alerts.

## Install

1. Download **DevSweep-0.3.0.dmg**, open it, and drag DevSweep to Applications.
2. This build isn't notarized by Apple, so allow it once:
   - **macOS 14:** right-click DevSweep in Applications, choose **Open**, then **Open** again.
   - **macOS 15 and later:** try to open it, then go to System Settings, Privacy & Security, and click **Open Anyway**.
   - **Or in Terminal:** `xattr -dr com.apple.quarantine /Applications/DevSweep.app`

## Verify the download

```
shasum -a 256 DevSweep-0.3.0.dmg
```

It should match `DevSweep-0.3.0.dmg.sha256` attached to this release.
